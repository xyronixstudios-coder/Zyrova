# Zyrova

Akcici bir akis. Akilli cache.

TikTok benzeri, global, reklamsiz, akilli cache kullanan sosyal medya platformu.

## Ozellikler

- Android + Linux (Flutter)
- TikTok tarzi video feed
- Begeni + Yorum
- Takip sistemi + Arkadaslik
- DM (fotograf + emoji)
- Bildirimler
- Profil + Banner
- Tema + Dil
- SmartCache (200 MB)
- Supabase backend
- Gizli hesap

## Kurulum

flutter pub get
flutter run -d linux
